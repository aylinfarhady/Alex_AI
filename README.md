# Alex AI 

Alex AI is a personal artificial intelligence assistant project built with Python.

The goal of this project is to create an intelligent assistant with memory, personality, and voice interaction capabilities.

## Features

- Memory system
- Personality model
- Custom response system
- Voice interaction (in development)
- Modular project structure
